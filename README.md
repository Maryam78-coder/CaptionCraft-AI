## Features
- Upload multiple images
- Generate AI captions with BLIP
- Score captions with CLIP
- Add subtitles to images
- Download results as ZIP

## Quick Start
1. Click the Colab badge above
2. Run all cells
3. Upload your images
4. Download captioned results!
